## 使用

1. 从资料目录进入章节，打开带页码或段落的正文；需要核对时打开原文件。
2. 检索题干关键短语及每个选项的实际内容。返回的是证据候选，须核对限定条件、术语、数字和时间。
3. 先确定答案内容，再映射当前选项字母。遇到资料不足、OCR 或平台答案与解析冲突时，单独标明，不冒充已核实。

终端检索，末尾替换为需要的短语：

```bash
python3 "工具/search.py" "神经中枢" --limit 3
```

可加 `--document KB001` 限定资料、`--section 第1节` 限定节名、`--json` 导出完整命中内容。不同章可能有相同节名，需核对章名。支持中文及跨换行候选检索；规范化保留小数点、斜杠、负号、百分号及数学符号。无命中不代表原文一定没有相关内容，可缩短短语后查看原页。

默认同时检索课件和题集。加 `--source-kind quiz_platform` 只查平台题集；加 `--source-kind course_material` 只查课程资料。用 `--document QUIZ-1.3` 可限定 1.3 试卷。题集结果保留选项实际内容，平台答案与解析分别显示。
