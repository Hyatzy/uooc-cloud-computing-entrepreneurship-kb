## 第 9 页

技术趋势 - 阿里巴巴 在线分析 发展演进历程
- ~2008 Oracle RAC：具备 Realtime, Consistency, Agility, Accuracy；局限 High concurrency, Volume（商业 单机 → 商业 分布式）
- 2009 Greenplum：具备 Volume(~PB), Agility, Accuracy；局限 High concurrency, High availability (leadernode), Realtime Write（商业 → 开源）
- 2011 HBase / MySQL Sharding / Hadoop：具备 Volume(~PB), High concurrency, Low Latency, Accuracy；局限 Consistency (offline/online), Agility (Cube)
- 2012 AnalyticDB 1.0：具备 Volume(~PB), High concurrency, Agility, Low Latency, Accuracy, High availability；局限 Consistency (offline/online), Realtime Write, ACID（开源 → 自研）
- 2017 TSDB
- 2019 AnalyticDB 3.0：具备 Volume(~100PB), High concurrency, Agility, Low Latency, High availability, Accuracy, Realtime RW, Cloud-Native；局限 ACID

## 第 10 页

技术趋势：单机 → 分布式
- Single Node：Network → DB → Disk
- Shared Everything：Network → DB / DB / DB → Shared Storage（Scale Up）
- Shared Nothing：Network → DB+Disk / DB+Disk / DB+Disk / DB+Disk（Scale Out）

## 第 11 页

技术趋势：OLTP + OLAP → HTAP
- OLTP（Native Engine：Shared Nothing / Shared Everything） + OLAP（External Engine / Native Engine） → HTAP

## 第 12 页

技术趋势：On-Premise → Cloud Native
- Master / Sync / Slave → RW / RO + Distributed Storage → L / F / F + Distributed Storage（Row Store + Columnar Store）
- 核心特性：极速恢复和复制、跨AZ、Large-Scale

## 第 13 页

技术趋势：结构化数据 → 非结构化融合分析
- AnalyticDB：文本模型、人脸模型、语音模型；结构化&非结构化 融合存储；分布式计算、融合分析、高效索引、硬件加速
- SQL + X：结构化数据分析、ML/DL 集成、文本分析、图像分析、视频分析、声纹比对

## 第 14 页

技术趋势：云边一体化
- 边缘侧：设备 → 设备接入 → 消息路由 → 云代理 → 边缘存储分析（Smart Proxy） → 多维数据分析 → 本地数据看板
- 云端协同：边缘管理中心（部署运维、设备管理、IoT公有云平台）；云端存储分析 → 智能化分析 → 云端 IoT Studio

## 第 18 页

AnalyticDB for MySQL 3.0重磅升级
- 云原生架构：基于容器技术，轻量化；用户集群隔离独享；全球部署
- 性能大幅提升：写入性能提升50%；查询性能提升40%；TPC-DS性能全球领先
- MySQL更兼容：支持最多256个数据库；更好的MySQL协议兼容性；全面兼容MySQL权限体系
- 读写强一致：基于Raft协议保证强一致；数据写入立即可见；ETL的ACID完备能力
- 弹性扩缩：存储从GB->PB扩展；节点弹性扩缩；弹性计算节点（即将推出）
- 数据更可靠：数据三副本可靠性保障；任意时间点恢复；只读实例、同城容灾
