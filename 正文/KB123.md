# 灾难恢复能力国家标准等级
- **等级 3（RPO/RTO 天级别）**：一般业务 | 至少每天备份一次 | 同机房主备 + 云上冷备
- **等级 4（RPO/RTO 小时到天级别）**：重要业务 | 每天全备 + 增量 | 同城主备 + 云端冷、热备
- **等级 5（RPO 30 分钟，RTO 分钟-小时）**：关键业务 | 实时复制技术 | 备份系统就绪或运行状态 | 同城主备 + 云端热备
- **等级 6（RPO 0 分钟，RTO 数分钟）**：核心业务 | 数据 0 丢失 | 备份与生产处理能力一致 | 分布式强一致数据库系统

# 阿里巴巴数据库从灾备到多活的发展历程
- **2012（异地冷备+热备）**：数百公里、备库可读、异地缓存失效、最大痛点：延时、成本
- **2013（同城双活）**：近距离验证、可读可写、场景摸索
- **2014（异地双活）**：上千公里、完善配套、容灾经验、由近及远打造基础设施
- **2015（中美同步）**：上万公里、冲突解决策略、网络传输优化
- **2016（异地多活+分布式强一致）**：多种数据源、金融级场景、PB 级数据同步、云产品化
- **2017~（云产品赋能）**：DBS 数据库备份服务、DTS 轻松构建异地多活、DMS + HDM 统一管理

# 数据库备份 DBS 与 数据传输服务 DTS
- **数据库备份 DBS**：数据库备份 Database Backup，它可以为多种环境的数据提供强有力的保护，包括企业数据中心、其他云厂商、混合云及公共云。
- **数据传输服务 DTS（页内小标题印作数据库备份 DTS）**：数据传输服务（Data Transmission Service）DTS 支持关系型数据库、NoSQL、大数据（OLAP）等数据源间的异构、异地数据实时传输。
- **架构对比（用户 IDC、其他云厂商 ↔ 阿里云）**：
  - **等级 3~4**：DBS 实时备份到阿里云 OSS（Slave / Master → OSS）
  - **等级 5**：DTS 单向同步，异地灾备（Slave / Master → Master / Slave）
  - **等级 5**：DTS 双向同步，异地多活（Slave / Master ↔ Master / Slave）

# 数据传输服务 DTS（双 11：大压力、低延时、长距离）

- **底座支撑**：Numan 运维平台

# 案例 3：云上异地多活 - UC
