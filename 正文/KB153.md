云计算服务新模型将为供应商  
提供挖掘数据中心的潜力  
导读： 如今，主要云计算供应商都会采用本地
硬件或特定技术，使其数据中心看起来更像公共
云。那么是什么推动了这一趋势的发展？  
 
如今，主要云计算供应商都会采用本地硬件或
特定技术，使其数据中心看起来更像公共云。那么
是什么推动了这一趋势的发展？  
为了使自己成为企业客户不可或缺的一部分，
大多数大型云计算服务公司正在共同努力挖掘内部
部署数据中心的潜力。云计算服务模式转变的核心
是帮助客户更轻松地管理混合云。  
云计算设备的引入最能说明云计算供应商为进
入数据中心所做的努力，这是微软、甲骨文和其他
公司正在销售的硬件设备。 这些设备为 IT 团队提供
了缓解和挑战，他们试图充分利用公共云，同时优
化其本地数据中心技术的使用。  
在其他情况下，软件就是云计算提供商用来拉
近客户距离的工具。例如， IBM Cloud Private 旨在
为用户提供私有云和公共云技术的组合。  
AWS Outposts 公司允许客户使用与公共云中相
同的 API，以便进行亚马逊公司认可的服务器处理
本地的工作。 微软公司将其 Azure Stack 定位为其云
计算服务的内部部署扩展。同样， Oracle Cloud at 
Customer 也会从客户的防火墙后面提供云计算服
务。与此同时，谷歌公司为希望通过谷歌云控制台
管理集群的客户销售名为 GKE On －Prem 的数据中
心版 Kubernetes Engine ，即使某些集群位于本地部
署的数据中心。  
其结果旨在创建一些人认为的单一提供商的混
合云。这些新产品（无论是硬件还是软件）都会为
IT 组织带来变化。那些采用提供商技术的人应该期
望减少一些责任和复杂性，也许更多地关注于确保
服务的顺利交付。  
修复私有云  
IDC 分析师 Rick Villars 称， 公共云及其相关设
备与近年来企业开发的私有云形成了鲜明对比。
Villars 说：“无论这些私有云是由它们自己的目录和
脚本组成的，还是组织只是选择使用 Rackspace 或
CenturyLink 等私有云， 这些新的公共云选项都更加
一致。” 
“基本上，每一个私有云都是独一无二的，但
这些新的选择在本质上都非常相似。”他补充道。  
现有私有云的主要限制是它们在提供组织所需
的内容方面缺乏灵活性。 Villars 说，“他们在容量和
存储方面进行了预先设计，如果希望增长， IT 必须
将整个系统整合为一体。”此外，这些系统很脆弱。
如果引入了新处理器，则必须从头开始。  
相比之下，这些新的云计算服务模型和平台（包
括其相关设备） 将会更加灵活。“现在这已成为一种
以消费为基础的模式。”Villars 指出。 
Villars 表示， 这些设备可以更轻松地为 IT 添加
存储或计算容量，以便将新技术整合到环境中，同
时保持日常运营。“坦率地说， 另一大好处是用户不
再担心补丁、修复和升级，并且随着时间的推移，
随着提供商实施改进和增强安全性，系统将会越来
越好。”他补充说。  
Villars 表示， 这些新产品为IT 提供的是真正的
现代化。而采用私有云是一种折衷方案，专注于提
供更现代化的数据中心。“用户拥有现有的 IT 负载，
但是希望能够更容易配置，并仍然降低运营成本。 ”
他解释道。  
Villars 说，“这并不是 IT 人士所说的那样，这
是创建新产品（例如精准医疗）的替代基础设施形
式，因为它很难复制和消费。相反，基于云计算的
新平台提供了专用场所，这样就能够以更多的 SaaS
方式开发和交付。” 
然而，Villars 指出，这些平台设计用于扩展到
边缘位置， 而不是用于处理传统的中心活动。“虽然
他们可能使 IT 以不同的方式运行数据中心， 但关键
是现在能够向工厂、游轮或医院提供类似 SaaS 的服
务。”他说。

新的云服务模型比比皆是  
调研机构 Forrester Research 公司分析师 Lauren 
Nelson 表示，关于能力的讨论以及 IT 负担也必须包
括成本。新选项可能有用，但并不便宜。而且与
Villars 的观点一致，她表示，愿意支付费用的用户
最有可能成为具有不同需求的组织，例如在岛屿、
军事基地和游轮运营设施的组织。  
但其成本到底有多高？很难得出准确的数据。
但 Nelson 指出，微软的 Azure Stack 可以说是市场
上的第一个产品， 其价格昂贵。 她说：“这一事实基
本上限制了其使用范围，但它确实为 IT 提供了部署
自由。”这不仅是因为用户可以将一个应用扩展到多
个地方，而且因为随着时间的推移，可以更容易地
迁移这些应用程序。  
在这些不断变化的云服务模型中具有一些吸引
力。 对于IT 人员来说， 大型基础设施投资被视为风
险投资，因为可能需要五年或更长的时间才能得到
回报。Nelson 说，到那时，他们的组织可能有不同
的云计算策略。 她说，“有了这些新的产品， 云计算
服务提供商就开始考虑购买基础设施，从架构的角
度来看，它看起来就像云计算。” 
Nelson 说：“人们面临的最大挑战是决定他们愿
意支付多少费用才能真正实现这一目标。 ” 
在更加注重运营的方面，调研机构 Gartner 公司
分析师 Ed Anderson 对 IT 的影响作了进一步的区
分。他说，“云计算提供商提供的硬件系统通常是
锁定的系统， 完全由云计算提供商或其合作伙伴管
理。这种类型的产品破坏了经典 IT 的作用，而经
典 IT 在这些解决方案的管理和管理中基本上没有
起到作用。” 
因此，实际上，基于云计算的新设备将传统的
企业数据中心转变为云计算提供商的一种托管设
施。“传统 IT 的含义是，除了将其插入电源和网络
之外， 它们在系统管理中基本上没有任何作用。”他
说。但是在操作上， IT 必须关注这些系统提供的服
务的消费，实质上需要确保用户满意。  
Anderson 表示，相比之下，来自云计算提供商
的软件现在可以通过这些不断变化的云计算服务模
式在私有数据中心中使用。例如，将 Google Kube-
rnetes Engine 置于客户数据中心的 GKE On-Prem 或
Amazon RDS on VMware ，提供 IT 专业人员可以与
之交互和管理的新型技术，通常这些将仅用于与公
共云服务兼容。  
Anderson
指出，由于云计算业务模式基于大规
模的标准化，因此将云计算服务推向私有数据中心
必须保持与公共云服务相同的标准化水平，以保护
整体云模型。因此，必须由云计算提供商锁定和管
理 Microsoft 的 Azure Stack 、AWS 的 Outpost 、Oracle
的客户云和其他类似产品等服务。他表示，无论如
何划分，这都会减少 IT 专业人员的责任。
