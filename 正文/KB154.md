摘  要 ：云计算是一个开放式的计算架构，通过互联网为用户提供各种服务，这
种方式可以使用户方便地使用云计算服务，但也导致其面临严重的安全威胁。因此，
解决云计算中的安全问题是云计算能否进一步发展的关键所在。要实现对云计算中数
据与隐私的安全保护，通常采用的方法是加密、访问控制和信息流控制等。加密和访
问控制的方法不能防止系统中隐藏信息流，因此无法完全隔离云计算服务中的用户。
信息流控制模型可以解决隐藏信息流这一问题，因此可以有效地隔离云计算中的用户。
文章基于信息流模型研究领域的重要模型（IP 模型）提出了云计算架构下的信息流安
全（SMCCIP）模型，该模型可以检测云计算架构中是否存在隐藏的信息流，保证云计
算用户间的隔离性。
关键词 ：云计算安全模型 ； IP 模型 ； 信息流控制 ； 信息安全

Abstract: Cloud computing is an open architecture that provides users with a variety 
of services over the internet. This approach poses a variety of threats to cloud computing, so 
security is the key to cloud computing’s ability to grow further. To achieve data and privacy 
security, encryption, access control and information flow control is the most effective way, 
encryption, access control cannot control the hidden information flow. In this paper, the 
security model of cloud computing architecture based on IP (SMCCIP) model can detect 
whether there is a hidden information flow in the cloud computing architecture so as to ensure 
the isolation between cloud computing users.
Key words: cloud computing security model; IP model; information flow control;  
information security

云计算是继分布式计算、点对点计算和网格计算
之后的一种新的计算模型 ，并迅速成为计算机技术
发展的热点。云计算为动态和可展开的虚拟化提供了
一种新型的计算资源组织、分配和使用模式，使用户
能够随时随地按需访问共享资源池。云计算为用户提
供了高效便捷的云服务 ，具有开放性 、动态性 、数据
管理不可控制性及云计算中资源分布的不确定性等特
点， 这些特点使得数据存储和处理面临新的安全风险。
新的安全风险主要包括 ： 1 ）虚拟机安全风险。虚拟
化技术可以极大地提高计算资源、存储资源的利用效
率，但共享方式带来了数据泄露的风险，如虚拟机越
狱。2 ）数据集中风险。数据被集中存放在某个或者
几个数据中心，一旦数据中心被黑客攻破，所有的用
户数据将被黑客窃取。3 ）数据可用性风险。数据被
集中存放，一旦网络出现故障，那么云计算没有办法
为用户提 供 服 务。
加密、访问控制和信息流控制是实现对数据和隐
私安全保护的有效方法。加密和访问控制是成熟的安
全技术。 加密方法是对传输或者存储的信息进行加密，
在这种情况下 ，即使信息被泄露，信息获得者也无法
知晓信息的具体内容。加密算法的优势在于可以在公
开信道传递消息，其安全性取决于算法强度及密钥强
度。访问控制是对系统中客体的被访问权限和主体的
访问权限进行策略定义，满足访问控制策略的行为被
允许 ，不满足访问控制策略的行为不被允许 ，可以防
止非授权访问。信息流是系统中各个域间信息的流动，
信息流控制是对这些域间的信息流动进行控制，从而
使得域间的信息流动满足既定的安全策略。但是，既
有的加密算法、访问控制策略及信息流控制模型无法
完 全 迁移到云 计 算系统中。
因此，为实现云计算安全，国内外研究人员从密
码学角度、访问控制角度及信息流策略角度进行了大
量的研究并取得了 一定的成果。本文在这些研究工作
的基础上，从信息流策略角度出发，将云计算架构符
号 化 ， 修 改 已 有 信 息 流 模 型（IP 模型 ）使之适用于云
计 算服 务。

云计算安全问题的解决可以进一步推动云计算
的发展。目前 ，相关安全问题的解决主要依赖于密
码算法 、访问控制策略、信息流控制策略等。密码
算法方向中针对云计算的热点研究主要集中于全同
态密码算法，可以使得数据在密文状态下进行计算，
但其计算量巨大，没有普遍应用。访问控制策略主
要是已有策略的应用，由于云计算涉及各行各业，所
以数据访问权限的管理非常复杂 ，传统的策略还没
有解决这一问题。信息流控制策略主要针对状态机
等复杂度较低的系统，因此本文将云计算架构进行
映射 ，从而可以形式化描述。本文提出的 SMCCIP
安全模型主要判断依据是形式化描述的云计算架构
及其信息流策略是否得到满足。面对一个实际应用
的云计算系统，如何将该系统进行形式化描述是下
一步工作中需要解决的问题。
