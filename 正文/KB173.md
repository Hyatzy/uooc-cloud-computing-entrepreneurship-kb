基于安全生产法律的“云服务平台”营销推广策略研究
刘　敏  湖南安全技术职业学院
摘要：随着大数据和云服务技术的快速发展，各行业各领域相继建立具有精准客户定位的“云服务平台” 。本文将从安全生产法律
“云服务平台”的功能特点着手分析，对目前服务平台现状进行分析，从用户的角度分析需求，结合线上线下推广形式提出具体的营销推
广策略。
关键词：安全生产法律；云服务平台；营销推广
中图分类号：F713.36      文献识别码：A      文章编号： 1001-828X(2017)027-0322-01
2007 年“云计算”这一名词诞生，作为提供产业服务化的基
础，使生产流程的最终交付产品基于网络和信息平台的服务，该平
台就被称为云服务平台。云服务平台的接受程度由客户决定，客户
的接受度是云服务平台营销推广的关键。本文通过分析安全生产法
律“云服务平台”的功能特点，结合相关竞品平台现状，分析用户
特征，提出以用户需求为导向的营销推广策略，实现精准营销策略
定位。
一、安全生产法律“云服务平台”功能特点
安全生产法律“云服务平台”旨在基于大数据整合安全生产法
律知识形成资源库，为全国各类生产经营企事业单位及个人提供全
方位的安全生产专业法律服务。该“云服务平台”的功能特点主要
包括下面几点。
( 一 ) 一键查询功能
“云服务平台”利用大数据几乎整合了所有的安全生产法律知
识，并实时对安全生产法律法规及标准进行更新，用户在下载使用
该服务平台后，即可免费查阅除资源链接单位需要收费外的信息，
实现一键查询式服务。
( 二 ) 线上咨询功能
平台由从事专业安全生产法律服务的人员运营，能及时对用户
所提出的相关资讯作出解释和说明，并提供具有可行性的建议及方
案。
( 三 ) 定制式服务功能
该“云服务平台”融合诸多专业人士，可以线上接受安全生产
及法律事务方面的顾问式一对一顾问服务，以及各类法律方面的服
务委托。根据不同服务，划定收费标准，从而获得经济效益。
二、安全法律服务云平台现状及用户分析
( 一 ) 法律服务平台现状分析
当前安全生产法律方面的服务平台也越来越精细化，对于用户
来说，如何获得法律服务且可以快捷高效地解决问题，预防相关风
险，是其寻找法律服务的出发点。用户本身大多缺乏经验去判断相
关平台的服务质量，平时也较难接触到法律服务的提供者，因此通
过求助于安全生产法律“云服务平台” ，能够帮助其快速解决自身
困惑。
( 二 ) 法律服务平台用户分析
根据 2016 年平安人寿联合闪电律师发布的《线上法律咨询用
户行为分析白皮书》显示，手机 APP“平安金管家”中“问律师”
服务上线 100 天内，累计注册用户 78.1 万人，下达咨询订单 15.1
万个，超过了同期北、上、广、深四个一线城市的司法援助咨询接
待量 ( 约 9.1 万次 )，由此表明互联网法律服务的强大需求量。
基于大数据和互联网下的安全生产法律平台致力服务于安全生
产监督管理职能部门、企业、事业单位、个人和其它组织，提供安
全生产相关的法律、诉讼、知识及查询等服务，有着精准的客户定
位。因此“云服务平台”通过哪些渠道可以获得客户，是营销推广
策略的重点。
三、安全生产法律“云服务平台”的营销推广策略
从当前发展情况看，安全生产法律“云服务平台”受各类法律
服务平台及机构的影响，会流失一些客户。在市场竞争中，如何找
准渠道，赢得客户应用，是产品制胜的法宝。结合行业实际，本文
为安全生产法律“云服务平台”提出选择线下线上相结合的全渠道
推广策略，充分整合资源，挖掘优势，提升安全生产法律“云服务
平台”的市场占有率。
( 一 ) 线下渠道策略
线下渠道作为用户直接体验的第一现场，应注重用户现场体验
的舒适性、服务的专业性、流程的高效性。例如，在具体的渠道应
用上，利用会议、讲座、论坛等形式推动安全生产法律“云服务平
台”快速落地，利用公益活动等增强客户对平台的信任感，成为将
客户导入“云服务平台”的工具。
( 二 ) 线上渠道策略
线上渠道应注重便捷高效的用户体验感，可通过加载各类数据
和资源服务，提供 24 小时不间断服务。这需要一方面专注自身线
上渠道建设，在保证服务质量的同时，更加注重与同类型服务产品
之间的差异化。另一方面则需强化业界的融合及跨界的整合，加强
与高校、法律机构、相关专家学者等实现资源共享和合作共赢，达
到运营成本利用最大化，获取较好的经济效益。在具体的线上渠道
选择上，应注重移动渠道嫁接、电商平台资源整合、法律平台融
合、媒体等。
1. 移动渠道嫁接。目前智能手机普及量呈现爆发式增长，成为
媒介传播的主要设备渠道
[3]
。安全生产法律“云服务平台”可以利
用手机 APP，通过加载教育、培训、考试、商务等非法律类服务，
利用用户习惯，促使线上和线下密切融合，促使移动渠道嫁接成为
安全生产法律“云服务平台”吸纳广大用户的重要渠道。
2. 安全生产法律平台融合。通过对安全生产及法律同行业的平
台进行融合，形成高效便捷、互利共赢的云服务平台。例如通过核
心技术挖掘，客户资源导入，或者并购，或者合作等方式，通过整
合各类同业资源，形成集聚优势，实现在较短时间获得最好的效
果。
3. 新媒体营销渠道。在传统媒体营销渠道方面，可借助广播、
电梯广告等宣传推广，为安全生产法律“云服务平台”上线进行造
势。但随着新兴媒体的大肆宣传及应用，新媒体渠道的应用将会快
速将该服务平台进行推广，包括微博、微信、APP 等。例如，在微
信方面，微信公众号、订阅号，微信群及朋友圈的应用，以及微信
广告定投等，皆可以快速将该服务平台推送给受众。
四、结语
本文从营销推广策略的角度，对安全生产法律“云服务平台”
的功能特点进行了梳理，对产品现状和目标用户进行归纳，基于安
全生产法律的“云服务平台”凭借精准的客户定位，如何与用户建
立更为密切的联系，本文给出具体的线上和线下的营销推广渠道，
以互联网技术为依托，为安全生产法律“云服务平台”的成功运营
提供推广策略建议。
