摘    要
随着科学技术的快速发展，近年来我国云计算领域发
展迅速，云计算技术的应用范围也不断扩展。基于此，本
文简单分析了广电系统中云计算核心技术的优势及应用思
路， 并围绕广电网络运维支撑系统、 广电机房环境监控系统，
深入探讨了云计算在广电系统中的应用实践，希望由此为
相关业内人士带来一定程度的启发。
关键词
云计算    广电系统    网络运维支撑系统    
机房环境监控系统
作为现阶段最受关注的话题和新技术，云计算在计算
机及互联网行业的应用极为广泛，如何将云计算核心技术
引入广电系统受到了业界的高度关注。 深入分析可以发现，
我国广电系统具备业务系统庞大、系统模块固化、新业务
层出不穷、管理日趋复杂等特点，这些都为云计算技术的
引入与应用提供了契机，本文研究的现实意义也由此得到
了证明。
一 云计算核心技术的优势
1. 编程模型科学简便
云计算技术采用 MapReduce 作为编程模型，该模型具
备科学、简便特征，属于典型的高效任务调度模型和分布式
编程模型，模型可较好服务于并行运输和大规模数据运算。
2. 海量数据分布存储
由大量服务器组成的云计算系统能够基于海量数据
分布存储技术提供服务，配合分布式存储方式，服务可较
好利用冗余存储，且能够较好保证数据的可靠性。开源
HDFS（Hadoop Distributed File System） 、GFS（Google File 
System）均属于应用较为广泛的云计算数据存储系统，这
类系统便具备鲜明的海量数据分布存储特点
[1]。
3. 可实现高效虚拟化
通过应用虚拟化技术，云计算技术可实现底层硬件与
软件应用的隔离。云计算中的虚拟化技术可细分为两种模
式，一方面为基于多个资源的虚拟资源聚合模式，另一方
面为基于单个资源的虚拟资源分裂模式。按照虚拟对象进
行划分，云计算的虚拟化技术可细分为网络虚拟化、存储
虚拟化、计算虚拟化。
4. 管理能力较为优秀
云计算技术的管理能力较为优秀，这种优秀的管理能
力主要源于海量数据的管理和大量服务器的协同工作。围
绕分布、海量的数据，云计算技术能够实现较为高效的管
理，例如互联网的搜索问题，先利用爬虫收集网页，存储到
BigTable 里，MapReduce 计算扫描全表生成搜索索引，最后
从 BigTable 中查询搜索结果以便展示；通过应用大量服务
器的协同工作，云计算技术可快捷、方便地开通和部署各
类业务，系统故障的快速恢复、智能化与自动化机的系统
运营均可由此实现，云计算核心技术的优势可见一斑
[2]。
二 云计算在广电系统中的应用思路
1. 助力三网融合
在广电系统中，云计算技术可较好服务于三网融合。
受三网融合影响，广电系统的业务规模与种类不断扩展，
这种情况下云计算技术的应用便存在较高必要性。在具体
应用中，云计算技术可负责提供三网融合的相应端口适配
支持、为不同运营商提供相应的私有云计算，并助力于数

2. 保障数据安全
广电系统对数据安全存在较高要求，而通过应用云计
算技术，在强大的计算能力、完善的监控体系、金融级的

可采用云计算技术进行授权的加密处理，并实时监控用户
的解密过程，配合广电系统增值业务规模及范围的扩大需
要，云计算的价值可更好得到发挥 [3]。
3. 加强版权控制
随着全版权时代的来临，我国广电系统面临着较高的
版权控制挑战，如何实现更为精准的版权保护也受到了业
界的重点关注。在云计算技术支持下，该技术可保证用户能
够尽可能合理使用数字资源，内容提供者的权益也能够同
时得到保障，这种保障主要通过将加密内容上载到云端，
用户合法获得授权内容和数据资源实现，配合广电系统的
集中版权管理，即可保证广电系统更好适应全版权时代。
4. 提供互动渠道
受云计算、大数据、物联网、移动互联等技术快速发
展的影响，信息技术领域的革命对我国各领域均造成了较
为深远的影响，兼顾各种传输网络、不同服务模式、不同
业务形态的多屏互动与跨网联动需求也因此不断增长。在
云计算技术支持下，广电系统能够科学实现信息筛选、分
析、组合，并为特定人群精准提供信息服务，个性化、及
时化、有效化的信息服务可由此实现，智能广电建设也能
够获得有力支持，如基于云计算智能化的节目推荐、广告
植入便属于其中代表，配合云计算的分布能力，即可保证
广电制播与观众实现更为深入的互动。
5. 转变生产方式
除上述应用思路外，云计算核心技术的应用还能够有
效转变广电的内容生产方式，推进电视台采编播一体化的
技术革新。在云计算核心技术支持下，统一的内容生产平
台建设、新闻采编方式的革新、大众需求的深入 研究均可
获得有力支持，现阶段我国广电系统的发展形势、国家战
略的要求、业务发展的要求也能够较好得到权衡 [4]。
三 云计算在广电系统中的应用实践
1. 广电网络运维支撑系统
在基于云计算核心技术的广电系统建设中，基于云计
算技术的广电网络运维支撑系统属于其中代表，该系统以
GIS（Geographic Information System 地理信息系统） 为基础，
网络做通道，智能终端为载体，其能够满足网络的可靠、
安全、经济、正常等方面需求。主要由增值业务网管系统、
网络优化系统、运维流程管理系统、业务开通系统、服务
保障系统、资源管理系统、综合网络管理系统、设备网络
管理系统组成，系统可细分为四个层次，分别为客户支撑
层、服务管理与运营层、资源管理层、基础管理层，具体
划分如下：
 z 客户支撑层：该层属于 BSS（Base Station Subsystem 
基站子系统）层面功能，可满足客户的 SLA（Service L evel 
Agreement 服务等级协议）管理需要，也能够在云计算技术
支持下实现对客户特征、 用户行为进行趋势和阶段性分析；
 z 服务管理与运营层：该层主要负责提供覆盖全业务
服务的支撑功能，包括服务规划、服务分析、服务保障、
服务开通等；
 z 资源管理层：主要负责资源规划、资源分析、资源
保障、资源调度、资源就绪与开通等功能；
 z 基础管理层：主要负责进行流程状态的合作伙伴管
理、 运维管理、 跟踪管理、 系统管理，以及综合事务管理等。
在广电网络运维支撑系统中，云计算技术的应用主要
体现在两个方面，分别为服务器虚拟化和存储虚拟化，具
体应用如下：
 z 服务器虚拟化。云计算技术可映射物理资源为虚拟
资源，并保证虚拟资源的使用实现相互独立，由此物理计
算机即可在云计算支持下实现多个独立操作系统的独立运
行与应用，且这类应用环境可实现服务器上所拥有资源的
共享。在具体的服务器虚拟化探索中，必须充分结合广电
网络运行支撑系统特点， 以此合理选择技术，并同时将功

服务器区，并保证三个区域管理的一致性，配合防火墙进
行安全域划分和物理分割，并结合云计算形成可控制的有
效策略，由此核心系统安全即可得到保障；

2. 广电机房环境监控系统
除广电网络运维支撑系统外，广电机房环境监控系统
也能够充分应用云计算技术。深入分析可以发现，广电机
房环境监控系统的机房站点大多分散于城乡各地，由于多
数机房无人值守、距离较远且精密设备众多，如何开展高
效率、高水平的管控工作向来受到业界重视，而通过引入
云计算技术优化广电机房环境监控系统，即可实现围绕红
外、烟感、图像、温湿度、UPS、光电设备、机房供电设备
的自动化与智能化的监控管理，参数分析、 集群容量控制、
告警功能也能够同时得以实现。
在基于云计算技术的广电机房环境监控系统建设中，
设计人员必须明确标准化、 可扩展、 可控、 可测、 可管目标。
在广电机房环境监控系统建设中，云计算技术主要负责提
供统一调度和管理基础资源虚拟化形成的资源池，以此为
用户提供基础设施服务、平台服务、软件服务，因此云计
算技术在 其中的应用可形成一个云平台管理和三个逻辑层
次，即资源层、平台层、应用层，其中资源层由物理资源
与虚拟资源组成，平台层由云平台框架与云平台服务组件
组成，应用层由多元应用、客户应用、标准应用组成，由
此云管理平台即可满足调度监控、 用户服务、 管理功能需要。
作为云计算的“神经网络” ，云平台管理技术可实现介质录
像机、信号采集服务器的协同工作，故障的快速发现与恢
复、云平台智能自动运营管理均可由此实现。
以某地基于云计算技术建立的广电机房环境监控系统
为例，该平台中的单站点由网络交换机、Web 浏览、硬盘
录像机、RS485 接口、现场嵌入式服务器、现场语音、手
机短信、声光报警、发电机、防雷器、红外、照明、配电
开关、配电、温湿度传感器、漏水检测、精密空调、UPS
电源、门禁、蓄电池组成，中心机房可接收各站点处理后
的数据冗余、信息，并应用云计算技术实现集中管控。此
外，系统的手机短信报警功能同样得到了云平台的支持，
通过应用 “云计算”的计算模式，可配合计算资源的共享
得以实现，各站点机房的运营监测功能提高、故障的精确
定位、成本的节约、管理效率的提升均获得了有力支持。
总的来说，云计算技术在广电机房环境监控系统中的应用
主要体现在广电光电设备监控、供配电监控、数字电视网
管参数与运行质态监控，云计算技术在广电系统中的应用
价值由此得到了更好证明。
四 结论
综上所述，云计算核心技术能够较好服务于广电系统
的建设与升级，在此基础上，本文涉及的助力三网融合、
保障数据安全、加强版权控制、提供互动渠道、转变生产
方式、广电网络运维支撑系统、广电机房环境监控系统等
内容，则提供了可行性较高的云计算技术应用路径，而为
了更好发挥云计算技术优势，云计算技术在广电系统中应
用可能面临的政策导向、资金配套、行业趋同等问题必须
得到重视。
