私有云平台部署是为了解决传统信息系统硬件资源浪
费，部署步骤繁琐。使用容器部署可以用短短几行命令完成
Docker 任务的发布，让保存于镜像中的服务运行起来，省去
了虚拟机安装和配置的繁琐步骤。最后再使用容器的环境构
建出开源在线协作平台。本文通过收集有关云平台搭建以及
容器部署的文献，总结了云平台搭建的相关理论及经验，对
整个系统进行不断的调整 , 最终能够高效快速的搭建出属于
自己的私有云平台。
一、环境准备
部署 Zstack 建议的最低系统配置要求如下 :
1. 主机：物理机的 CPU 不低于 4 核心，需支持 x86 架
构的硬件虚拟化特性；
2. 内存：8G 以上；
3. 网络：物理机需配置千兆网卡；
4. 存储：主存储或镜像存储均建议 2T 以上容量。
二、云平台部署
由 于 VMware Workstation 的 计 算 机 虚 拟 能 力， 性 能
与物理机隔离效果非常优秀。功能非常全面，在 VMware 
Workstation 中，可以在一个窗口中加载一台虚拟机，它可以
运行自己的操作系统和应用程序。可以在运行于桌面上的多
台虚拟机之间切换，通过一个网络共享虚拟机，挂起和恢复
虚拟机以及退出虚拟机，这一切不会影响你的主机操作和任
何操作系统或者其它正在运行的应用程序。 操作也十分简单，
所以选择 VMwareWorkstation 中安装部署 Zstack。在 VMware
安装操作系统，因为 Zstack 是基于 CentOS 深度定制所以操
作系统选择 linux 版本选择 CentOS 64 位。安装好以后就会进
入 TUI。TUI 主界面会实时显示物理机的主要信息，管理节
点当前状态， 包括服务是否运行、 UI 是否运行、 ZStack 版本、
UI 地址， 显示服务器启动时间、 当前时间、 服务器运行时长、
服务器平均负载等管理节点所有网卡的信息以及当前集群该
管理节点的实时资源利用率。
三、云平台初始化
1. 进入云平台 UI 后，系统界面将引导进行 ZStack 私有
云平台基本的初始化环境配置。然后创建集群区域是 ZStack
中最大的一个资源定义， 包括集群、 二层网络、 主存储等资源。
2. 添加物理机和镜像服务器，普通用户要求拥有 sudo
权限。
3. 添加主存储，主存储类型选择本地存储。主存储用于

四、容器安装部署
1. 云主机创建好以后使用 yuminstall 命令安装 docker；
2. 安装完成后使用 Docker -v 命令查看当前 docker 版本；
3. 使用 systemctlstart 命令启动 docker 服务；
4. 使用 systemctlstatus 命令查看 docker 服务启动状态。
五、Docker 镜像操作
为了能够快速访问 Docker 镜像可以通过 Docker 官方镜
像加速享受到更快的下载速度和更强的稳定性，从而能够更
敏捷地开发和交付 Docker 化应用。
1. 通过修改 /etc/docker/daemon.json 文件配置镜像加速；
2. 在配置文件中修改“--registry-mirror”参数，修改以
后重启 docker 服务；
3. 使用 dockersearch 命令查找需要的镜像因为 dzzoffice
需要的环境是 mysql+php 所以我们查找 lamp 镜像；
4. 通过 docker pull 命令拉取镜像；
5. 使用 Dockerimages 列出 docker 下的所有镜像；
6. 使用 Docker run 命令创建容器并命名；
7. 使用 dockerps 查看所有的容器。通过以上步骤可以看
见容器已经在运行了。
本文通过对云服务模式进行分析从企业自身的需求出发
介绍了如何搭建一个完全属于自己的私有云系统平台。解决
了传统信息系统硬件资源浪费、软件开发及应用周期长，服
务器部署不灵活等缺点。私有云平台虽然有很多优势，但是
现在仍然处于发展阶段，依然有许多的不足，首要问题就是
安全问题，因为现在的用户更多的是通过计算机系统来获得
相应的 IT 技术服务，那么在进行系统的构建过程当中，就
需要考虑到主机安全、系统安全以及网络安全等众多安全问
题。云平台可以将用户的数据信息进行高度的整合，这样就
能够将用户的安全隐患转移给云平台终端，相对而言，云平
台在安全问题的防范上更加可靠。
