资讯 INFORMATION
欧洲司法法院宣布数据安全法中对个
人数据的定义包括 IP 地址，即动态 IP 和
静态 IP。将 IP 地址纳入个人信息保护将
对互联网企业造成重大影响。德国法院的
解读是，不管访问行为是否结束，对包括
IP 地址的日志等存储内容，都是对个人
数据的保存行为。
微软业绩报告显示，上季度净利润为
47 亿美元，或每股 60 美分，营收为 205
亿美元。不包括一次性项目在内，微软的
利润为 60 亿美元，或每股 76 美分，调
整后营收为 223 亿美元，超出华尔街此
前预计的调整后营收 217 亿美元和每股
利润 68 美分。微软云计算和服务器业务
表现强劲，Windows 业务的情况略好于
微软预期，而手机业务销售则持续滑坡，
营收同比下降了 72%。微软表示，云计
算业务的增长并没有以牺牲微软传统服务
器软件为代价。服务器和商业云计算业务
的合并后营收同比增长 11%。
【评论】云计算服务商在前期连续数年投
资巨大，技术服务领先者赢得大部分市场
份额。美国企业级市场更加成熟，需求量
与云普及度领先中国 3 年，本季度微软云 
Azure 收入增长 116%，亚马逊 AWS 上
个季度同比增长 31%，而阿里云则季度
同比增长 156%，全球 3 大云服务商都在
利用各自生态优势开拓“混合云”市场，
在中美竞争 IaaS 市场份额外，快速迭代
PaaS 服务，帮助本国所有软件开发企业
拓展行业 SaaS 盈利空间，云计算是巨头
生态间的竞争与合作，依靠规模为企业用
户提供高性价比服务，中小型服务商将面
临优胜劣汰与整合并购。
【评论】欧洲法院是欧盟最高法院，本次
将 IP 地址纳入个人数据的范畴对于企业
的直接影响是包含用户 IP 地址的日志等
数据将不能离开欧洲，这意味着，未来在
欧洲开通服务的互联网企业，凡涉及用户
IP地址的数据， 都需要在欧洲范围内处理。
目前我国网络安全法草案二审尚在征集意
见当中，IP 地址是否有可能也纳入到个
人数据定义中，尚需讨论。
