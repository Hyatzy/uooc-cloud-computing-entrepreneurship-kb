## 转换工具与复现

原项目：[caj2pdf/caj2pdf](https://github.com/caj2pdf/caj2pdf)，固定提交 `6c4bc32b15ce748d211f45d536f5d5511ef9f368`。保存在 `工具/caj2pdf-upstream`。使用现有 Python/PyPDF2/PyMuPDF、编译器和 Homebrew libjbig2dec；没有新装Python包。只调用CAJ/HN路径，没有调用解密功能。

在 `工具/caj2pdf-upstream` 目录编译所需小型图像解码库：

```sh
c++ -Wall -fPIC -shared -o libjbigdec.so lib/jbigdec.cc lib/JBigDecode.cc
c++ -Wall -fPIC -shared -I/opt/homebrew/include -L/opt/homebrew/lib -o libjbig2codec.so lib/decode_jbig2data_x.cc -ljbig2dec
```

在知识库目录执行：

```sh
python3 工具/caj_convert.py
python3 工具/caj_hn_pdf.py
python3 工具/caj_hn_text_extract.py --help
```

`caj_convert.py`采用原项目的CAJ内嵌PDF对象重建过程，将mutool交叉引用修复和旧PyPDF2目录写入替换为现有PyMuPDF。`caj_hn_pdf.py`重建原图并保留目录，`caj_hn_text_extract.py`独立提取HN原文字层和逐页元数据。
